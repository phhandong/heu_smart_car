原理 · ① 反馈

控制就是：拿实际值和目标比，再决定下一步做什么

接水、骑车、调电机，做的都是同一件事。
01 目标

想要多少

接满一杯水；电机每 5 ms 转 50 个计数。

r = 50
02 测量

现在多少

眼睛看水位；编码器数这一拍的增量。

y = 43
03 比较

差多少

还差 7 个计数。这个差值，是后面所有计算唯一的输入。

e = r − y = 7
04 执行

多给一点

水快满了就关小；电机慢了就把占空比加上去。

u += Δu

换个说法

控制不是“把输出设成某个值”，而是“每个周期看一眼结果，再决定下一步改多少”。前者是开环，后者是闭环。

最容易翻车的一步 目标用“50 个脉冲”，反馈却换成 rpm 去减。量纲不一致，后面怎么调都不对。
记住这个问句 现在差了这么多，下一步输出该变多少？PID 就是这句话的一个具体答案。
三件事都要成立 测量要准、比较要同量纲、执行要够快。缺一个，闭环就调不出来。

每一拍看一次结果：目标不动，实测追上来，偏差越来越小。

开环与闭环：差的就是那条反馈线

同一个目标、同一台电机，多一个 Σ 和一条反馈，系统就不一样了。

开环：输出只是被看见，不参与决定。闭环：每 5 ms 把实测值送回比较，差多少补多少。

控制与计算 出力与驱动 电机 反馈与编码器
只多了一条线，代价在后面 传感器、固定周期、参数，都要跟着来。

原理 · ③ 抗干扰

闭环为什么能抗干扰

干扰一出现，闭环马上知道“不对劲”；开环永远不知道。

同一条负载扰动：开环掉下去就回不来，闭环掉一点就被补回来。

负载变大

上坡、压到地面、轮子阻力变大。转速一掉，偏差变大，占空比自己加上去。

电池电压下降

电量低、大电流时压降。同样的占空比出力变小，闭环会多给一点。

摩擦与温度变化

轴承磨损、温度升高。这类慢变化，靠积分项一点点补上。

但闭环不是万能的 目标超出电机能力（比如空载都到不了 80 个计数）时，怎么调都上不去。调参看三个数：掉多少、多久回来、稳态波动多大。

原理 · ④ 代价

闭环不是免费的

系统更“聪明”，也更难调、更容易振。

开环 给多少就是多少

  • 结构：一段赋值代码，给个固定占空比
  • 调参：不用调
  • 抗干扰：没有
  • 风险：几乎不会失控

闭环 看结果再决定

  • 结构：固定周期 + 反馈 + 控制器
  • 调参：按对象调 1–3 个参数
  • 抗干扰：有，但受输出能力限制
  • 风险：参数不当会振荡、顶满、反转

多出来的四样东西

传感器：编码器和接线；固定周期：每拍读、算、写，不能忽快忽慢； 参数：Kp/Ki/Kd 要按对象调；风险：参数不合适会振，越调越差。

什么时候可以不用闭环

负载基本不变、对速度要求不高（风扇、小水泵），开环给个电压就够； 车轮要按目标速度走、还要抗坡道和摩擦变化，就必须闭环。

问题 1

负载会变吗

坡道、摩擦、电池压降——只要会变，开环就稳不住。

问题 2

速度要稳住吗

差一点能接受就开环；要求跟着目标走，就得闭环。

问题 3

传感器和周期有吗

没有编码器、给不出固定周期，闭环免谈。

直流有刷电机里面有什么

四个部件，各干一件事；右边三步说明“为什么每半圈要换一次电流方向”。

剖面里 ①–④ 对应下排四张卡；三步图里电流方向在 90° 处翻转，转矩方向始终不变。

① 定子磁铁

提供恒定磁场。退磁 → 力矩明显变小。

② 转子线圈

通电后受安培力产生转矩。烧断 → 完全不动。

③ 换向器

每半圈交换一次接触片。磨损 → 抖动、异响。

④ 电刷

把电流送到转动的换向器上。磨损 → 火花大、接触不良。

器件 · 电机 ③

无刷电机：没有电刷，换相交给电路

转子是永磁体，定子是三相绕组；驱动器按顺序通电，磁场一步步转，转子被拖着走。

右侧六步会自动循环；亮的两个绕组就是当前通电的两相，箭头是合成的磁场方向。

六步换相 每 60° 电角度换一次绕组组合，磁场“跳”六次转一圈。任何时刻只通电两相，第三相悬空。
为什么复杂 必须先知道转子在哪（霍尔 / 编码器 / 无感反电动势），否则不知道该通哪两相。
和有刷的对照 都是“让电流跟着转子转”；有刷靠机械，两根线就行；无刷靠电路，必须配驱动和位置检测。

器件 · 电机 ⑤

负载一大，为什么转速就掉

电机转动时自己会产生“反抗电压”，转速越高，反抗越强。
1

转子切割磁感线，产生反电动势 E = Ke · n，方向和电源相反。

2

真正推动电流的是差值：I = (U − E) / R。

3

负载加大 → 要更大转矩 → 要更大电流 → I 变大。

4

U 不变、I 变大，只能 E 变小 → 转速 n 下降。

结论 只要电压不变，负载一变转速就变。想让转速不受负载影响，就得在负载变化时主动改 U——这正是闭环要做的事。

算一个例子

U = 6 V，R = 2 Ω，Ke = 0.01 V/rpm。

空载　I ≈ 0.1 A580 rpm
带载　I = 1.0 A400 rpm

同样 6 V，掉了 180 rpm。

闭环怎么补 发现只有 400，就把占空比从 50% 提到 70%，U 变 8.4 V，E 回到 5.8 V，转速回到 580。
U = E + I·R = Ke·n + I·R　→　n = (U − I·R) / Ke
堵转为什么最危险 n=0 时 E=0，电流只剩 U/R，是正常转动的十几倍——最容易烧电机和驱动。
反电动势还有别的用 无感无刷就是靠它判断转子位置；这里只要记住：它随转速升高而变大。

器件 · 编码器 ①

编码器：把“转了多少”变成数字

增量式有两种接口——正交 A/B 和带方向（PUL+DIR）；绝对式上电就知道在哪。测速只需要增量式。

正交 A/B 本次

两路方波差 90°，靠相位先后判向；4 倍频，分辨率最高；要两路输入。

带方向编码器

一路脉冲 PUL + 一路方向电平 DIR；DIR 直接表示正反；1 倍频，接线少一根。

绝对式

每个角度位置一个唯一编码，上电就知道在哪；接口复杂、成本高。

左：一圈刻缝 + 错开 1/4 缝距的 A/B 两路，另有一个每圈一次的 Z。右：每个扇区自带编号，掉电也知道在哪。

Z 相干什么每转只出一个脉冲，用来“对零”：过一次 Z，计数就有了确定参考。
选型看三个数每转脉冲数（分辨率）、最高响应频率、输出类型（开漏 / 推挽 / 差分）。

测速：固定窗口内数增量

编码器给的是位移，配上时间才是速度。窗口越短越灵敏，计数越少越粗糙。

每 5 ms 开一次窗，数窗口里过了多少个脉冲；这个数就是这一拍的速度。

y = Δn / Ts　（count / s）
rpm = 60 × Δn / (C × Ts)
Δn（5 ms 内）C = 1040计数率
10115 rpm2000 count/s
25288 rpm5000 count/s
50（默认）577 rpm10000 count/s
1001154 rpm20000 count/s
量化误差 计数是整数，目标 50 时 1 个计数就是 2%，读数在 49/50/51 之间跳是正常的。
换算时只用 count 目标和反馈都用“每 5 ms 多少计数”，就不必关心电机型号、减速比和线数。C 不确定时，手转一圈数计数，以实测为准。

出力 · ① PWM

单片机怎么“给”出一个中间电压

IO 只会输出高或低；开关足够快，电机只感受到平均值。拖滑块试试。

橙色面积的平均高度就是平均电压；占空比一变，电机两端看到的电压就变。

6.0 V平均电压（12 V 供电）
2000空载转速 rpm（估算）
两个频率别混 开关频率 20 kHz 决定电流平不平滑、有没有啸叫；控制频率 200 Hz 决定多久修正一次。
100% 也不是全速 还有电池压降、驱动压降、电机内阻，实际总比理想值低一点。
为什么是 20 kHz 高于人耳听觉，电机不啸叫；周期 50 µs，电流纹波也小。
太低会怎样 电流断续、电机抖动、有可闻噪声；频率太高则开关损耗上升。

出力 · ② H 桥

方向由 H 桥决定，大小由占空比决定

单片机引脚只有毫安级电流，电机要安培级；H 桥负责功率放大和换向。

点右边的状态，看电流从哪两条腿走；同一桥臂上下一起导通就是电源短路。

一条硬规矩：不能直通 同一桥臂上下两个开关同时导通 = 电源短路。换向前先关断，必要时加死区（几十 ns 到几 µs）。
PWM 加在哪 常见做法是“一路 PWM + 另一路常低”，或两路互补 PWM；方向由导通组合决定，大小由占空比决定。
选驱动看三个数 耐压 ≥ 电源 2 倍余量、持续电流 ≥ 堵转电流、导通电阻决定发热。

实现 · ① 结构

把零件连成一条闭环

每个方框都对得上工程里的一个函数或一个外设；信号名和单位要一致。

目标 r 与反馈 y 都用 count/5 ms；控制器输出 u 是占空比，单位 %，限幅 ±100。

量纲要一致 拿计数去减 rpm 或占空比，怎么调都不对。
符号要正确 先确认“PWM 增大 → 计数增大”；反了就是正反馈，几拍顶满。
控制器是什么 拿偏差算输出的那个部件：输入 e，输出 u。换电机只改参数，结构不变。
实现 · ① 结构18 / 33
实现 · ② 节拍

每 5 ms 做四件事

读、算、写必须在同一个节拍里完成；跨节拍错位，控制器就拿旧数据做新决定。

一个周期 5 ms，四步加起来约 40 µs，只占 0.8%；剩下时间留给主循环刷屏和打印。

① 读编码器取走本周期增量 Δn，并清零计数器。
② 算转速y = Δn，单位 count/5 ms。
③ 算偏差e = 目标 − y，交给 PID 算 Δu。
④ 更新 PWMu += Δu，限幅后写比较寄存器，并把 u 一起发给 VOFA。
实现 · ② 节拍19 / 33
实现 · ③ 定时器中断

让周期不受主循环影响

主循环里用 while 延时算出来的周期不确定；一打印、一刷屏，周期就变了。

定时器每 5 ms 打断一次主循环，进 ISR 把“读、算、写”做完，几十微秒后返回。

ISR 里只做读计数 → 算 PID → 写 PWM，几十微秒结束。
ISR 里不要printf、刷屏、动态内存、while 等待。
volatile中断里改的变量要加，否则可能被优化掉。
原子性主循环读多字节变量可能被打断，读两次或关中断保护。

验收会这样问 “这个文件负责什么？改目标值要动哪一行？PID 公式在哪个文件？”——答不上来，说明还是堆在一个文件里。

PID · ① 三项

P 看现在，I 看历史，D 看趋势

同一台电机、同一个目标，只改参数，看四条曲线差在哪。

P 小：慢、停在下边；P 大：快但来回摆；加 I：静差消失；再加 D：峰值压低。

P：差多少补多少

输出 = Kp × 偏差。响应最快，但偏差为 0 时出力也为 0，所以纯 P 一定有静差。

I：把历史累加起来

误差消失后累加值仍在，正好提供维持转速的出力；太强会超调、来回摆。

D：看变化趋势

速度冲得太快时给反向修正，压超调；差分会放大计数噪声，速度环常常不加。

PID · ② 静差

只有 P，就一定会差一点

不是参数没调好，是结构决定的：误差为 0，P 的出力也为 0。拖 Kp 看稳态点怎么挪。

目标线不动，Kp 再大，稳态点也只能逼近、贴不上。

稳态：y = KvKpr / (1 + KvKp)
静差：e = r / (1 + KvKp)
Kv 是电机增益（这台约 1.25），不是 Kp
21稳态 y（count/5 ms）
29静差（count/5 ms）
结论 加大 Kp 只能把静差压小，消不掉；要消静差必须加 I。

PID · ③ 增量式

每次只算“变化多少”，再加回输出

位置式相邻两拍相减，就得到这一拍的增量；只依赖最近三次偏差。
Δu = Kp(ek−ek−1) + Ki·ek + Kd(ek−2ek−1+ek−2)
u = u + Δu
单位 三个系数都折算过 Ts，统一为“% / (count/5 ms)”，代码里直接用。
上电第一拍 e1、e2、u 必须清零，否则第一次的微分项是随机值。
先累加再限幅 限幅后的值写回 u，下一拍才从受限值继续加。
5 ms 中断里的速度环
/* 量纲统一：count/5ms 与 % */
static float e1, e2, u;

void speed_loop_5ms(void)
{
    int   n = encoder_read_delta();
    float y = (float)n;
    float e = 50.0f - y;   /* 默认目标 */

    float du = KP*(e - e1)
             + KI*e
             + KD*(e - 2.0f*e1 + e2);

    u += du;
    if (u >  100.0f) u =  100.0f;
    if (u < -100.0f) u = -100.0f;

    motor_set((int)u);
    e2 = e1;
    e1 = e;
}

PID · ④ 位置式

位置式：算出“这一脚该给多大”

输出就是控制量本身，误差多大油门就给多大；积分是一个要自己看住的状态。
u = Kp·e + Ki·Σe + Kd·(e − e1)
积分要限幅 Σe 会一直涨。输出顶到 100 之后积分还在累，松手就先冲一下——这就是积分饱和，必须单独夹住。
重启要清状态 integ、e1 不清零，第一拍就会带着上一次的积分跑。
改参数会跳 u 是直接输出，Kp 一改，工作点立刻变。要平滑，得做无扰切换。
一句话 它最像人开车：看着速度表，脚直接踩到某个深度。
同样的 5 ms 速度环
/* 位置式：输出全量，积分显式 */
static float integ, e1;

void speed_loop_5ms(void)
{
    int   n = encoder_read_delta();
    float y = (float)n;
    float e = 50.0f - y;

    integ += e;                     /* 积分显式累加 */
    if (integ >  2000.0f) integ =  2000.0f;  /* 抗饱和 */
    if (integ < -2000.0f) integ = -2000.0f;

    float u = KP*e + KI*integ + KD*(e - e1);
    if (u >  100.0f) u =  100.0f;
    if (u < -100.0f) u = -100.0f;

    motor_set((int)u);
    e1 = e;
}

PID · ⑤ 同一个公式

数学上是一回事，调起来是两回事

同一组系数算出的 u 一样；但先拧哪个旋钮、盯哪条线，是两套习惯。

位置式

u = Kpe + KiΣe + Kd(e−e1)

直接算全量，积分是显式状态。

相邻两拍
相减
→

增量式

Δu = Kp(e−e1) + Kie + Kd(e−2e1+e2)

只算这一拍的变化，再累加回 u。

关键结论 同一组 Kp/Ki/Kd，两种写法算出的 u 一模一样；但调参手感差很远——先拧谁、看哪条线，是两套习惯。

限幅

位置式夹住 u，integ 还在涨；增量式夹 u 就是夹状态，天然抗饱和。

重启

位置式要清 integ、e1；增量式要清 u、e1、e2。

噪声

位置式 D 是一阶差分；增量式 D 是二阶差分，同样的 Kd 更吃噪声。速度环干脆不加 D。

起手

位置式先给 P、盯 u；增量式先给 I、盯 Δu。先拧谁不一样。

所以 数学等价，不等于调参一样；也别把“增量式更先进”讲成结论。
自己验证一次 把同一组系数分别填进两种写法，曲线应该完全重合；不重合，先查限幅写回和上电初值。
PID · ⑤ 两种写法26 / 33
PID · ⑥ 三个旋钮

每个旋钮，都有“合适”和“过头”

同一台电机，只改一个量；左边是加到刚好，右边是加多了。

橙框那一列是“加过头”：P 过头抖、I 过头摆、D 过头毛。

一句话 P 管硬度，I 管静差，D 管趋势；三个都是过犹不及。加多了先退半步，再谈别的。

PID · ⑧ 两条路线

先调谁，取决于你看的是 u 还是 Δu

两条路都能到同一组系数，区别是起手先动哪个旋钮、看哪条曲线。

位置式：P → I → D

  1. P 加到“微微超调”振荡要少，别加到刚好不差
  2. 加 I一定要小，慢慢加；大了会低频摆
  3. 必要时加 D压超调；I 可以不加
  4. 每次只改一个量改完看三条曲线

增量式：I → P，D 基本不用

  1. I 加到“微微超调”让它微微振荡，别压平
  2. 加 P抑制振荡，同时加快响应
  3. 不加 D二阶差分吃噪声，看不出明显效果
  4. 每次只改一个量看上升、超调、受阻恢复
顺序不是定理 先 P 后 I 和先 I 后 P 都能到同一组系数；先给 I 会显得慢，是调法，不是算法。
记录参数 Kp/Ki/Kd、Ts、限幅、负载一起写进注释，不然下周就忘了。
先定数量级Kp/Ki 从 0.1、1 试起，别一上来给 10
一次一个量改两个说不清是谁的功劳
看曲线上升、超调、受阻恢复

PID · ⑨ 实际例子

实际项目里，内环外环各用什么

同样是 PID，内环盯执行器，外环盯目标；写法跟着场景走。
场景用什么为什么
电机速度环 本次增量 PI编码器计数有量化噪声，占空比要限幅，受阻后要立刻补
平衡车最内角速度环增量 PI内环周期短、输出限幅、噪声大，PI 够用
无人机最内角速度环位置 PID内环要快、要直接限幅，D 压超调
外环（角度 / 位置）位置 PD只给内环目标，不需要再积一次；D 提供阻尼
外环

位置 PD

角度/位置偏差 → 给内环一个目标速度

内环

增量 PI（或位置 PID）

速度偏差 → 给执行器一个占空比

执行器

限幅输出

电机 / 舵机 / 电调，u 有上限

规律 内环输出直接给执行器，偏增量 PI；外环只给内环目标，偏位置 PD。没有一条规则套所有——看执行器、看噪声、看要不要抗饱和。

烧录时不上电，烧完再上电

烧录全程电池断开、由下载器供电；确认程序能跑，再断电接电池。

1 断开一切电源

开关拨 OFF，电池插头不插。

2 接下载器

3V3 / SWDIO / SWCLK / GND，以丝印为准。

3 只插 USB

由下载器给板子供电，电池仍断开。

4 编译

MounRiver 里 Ctrl+B，确认 0 error。

5 下载

点 Download，等 Success。

6 复位观察

串口有打印，VOFA 里能看到 y 和 u。

7 断电接电池

先拔 USB，再插电池，最后开开关。

8 架空试转

轮子离地，确认方向与转速正常。

9 落地演示

确认无误再放地面，别一开始就带载。

轮子必须架空 下载后电机可能立刻转起来，落地会窜出去。

带电池能不能烧 可以，但电流突变可能让板子复位；仍建议先用 USB 供电烧录。
找不到芯片 先看下载器驱动和接线，再确认板子由 USB 供电。
下载成功但不转 先看串口有没有打印，再看 PWM 引脚和方向引脚。
一上电就窜 十有八九是方向反了或目标太大，架空再试。
